Ключ остаётся только в памяти этой вкладки. Его нет в коде сайта и на GitHub.

Где взять файл подключения?

Запустите pod/install.sh из комплекта сайта на поде. Файл /workspace/krea-connection.json можно скачать через Jupyter. При пересоздании пода загрузите новый файл. В API-workflow адреса сервера нет: workflow и подключение загружаются отдельно.

Как пользоваться

  1. Откройте сайт. После публикации: elisemarsha50-web.github.io/Krea2/ ↗. Сайт открывается и без пода; для генерации нужен работающий под.
  2. Подключите новый под. Дождитесь установки шлюза. В Jupyter скачайте /workspace/krea-connection.json. Нажмите «Подключить под» → «Загрузить файл подключения». При пересоздании пода загрузите новый файл.
  3. Загрузите workflow. В ComfyUI: File → Export (API). На сайте нажмите «Загрузить API» или «Вставить JSON». Проверьте выбранное поле промпта и сообщение о моделях. Сам API-файл не содержит адреса пода.
  4. Один или много промптов. Включите «Список промптов» и вставьте описания, разделённые одной или любым количеством пустых строк. Например, 20 описаний дадут 20 заданий. Обычные переносы строки внутри описания сохраняются. Для одного многоабзацного промпта выключите этот режим. Можно загрузить файл .txt.
  5. Выберите количество. «Изображений на каждый промпт» задаёт число отдельных заданий для каждого описания. 20 промптов × 2 = 40 заданий. Размер и шаги применяются ко всему отправляемому пакету.
  6. Нажмите «Добавить в очередь». Кнопка рядом с промптом остаётся доступной. Можно сразу менять текст и отправлять ещё. Отправка идёт без ожидания готового фото; один GPU обычно выполняет задания последовательно. Статусы и отмена — во вкладке «Очередь».
  7. Скачайте результаты. Откройте «Готовые кадры». Нажмите на кадр для увеличения, отметьте нужные фотографии и выберите «Скачать выбранные ZIP» либо «Скачать всё ZIP». Архив создаётся в браузере; фотографии не отправляются на GitHub.
  8. Перед закрытием вкладки сохраните кадры. Ключ, очередь интерфейса и галерея находятся в памяти вкладки. Обновление страницы сбрасывает их, но уже принятые задания могут продолжать работать на поде. Повторно не отправляйте пакет, пока не проверите ComfyUI.
Если под ещё без шлюза

Откройте терминал пода, скачайте pod/install-from-github.sh из репозитория и запустите его с адресом https://github.com/elisemarsha50-web/Krea2. Команды приведены в README репозитория. Для прямого ComfyUI после защиты: логин studio, пароль — ключ из файла подключения.
