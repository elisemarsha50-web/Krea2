# Krea Studio

Личная адаптивная студия для ComfyUI на Vast.ai. Сайт работает без сборки и зависимостей: HTML, CSS, JavaScript. Интерфейс предназначен для GitHub Pages и браузера телефона/ПК; генерация выполняется на вашем поде.

## Первый запуск

1. Загрузите содержимое этой папки в корень `https://github.com/elisemarsha50-web/Krea2`.
2. В GitHub: **Settings → Pages → Deploy from a branch → main → / (root) → Save**. Адрес: `https://elisemarsha50-web.github.io/Krea2/`.
3. На работающем поде запустите один раз:

```bash
curl -fL --retry 3 https://raw.githubusercontent.com/elisemarsha50-web/Krea2/main/pod/install-from-github.sh -o /workspace/install-krea-studio.sh
bash /workspace/install-krea-studio.sh https://github.com/elisemarsha50-web/Krea2
```

4. Скачайте `/workspace/krea-connection.json` через Jupyter. Файл появляется после создания HTTPS-туннеля, обычно за несколько секунд. Если его ещё нет: `supervisorctl status krea-studio krea-studio-tunnel`.
5. На сайте: **Подключить под → Загрузить файл подключения**. Можно вручную ввести `url` и `key` из этого файла.
6. Нажмите **Загрузить API** и выберите свой **Export (API)**. Если текстовых полей несколько, проверьте «Поле промпта». Обычный JSON с `nodes` и `links` не подходит. Можно вставить JSON текстом.
7. Напишите промпт и нажмите «Создать изображение». Кадры можно увеличить и скачать.

Установщик перезапускает только свободный ComfyUI. Если есть активные или ожидающие задания, установка остановится и попросит повторить позже. Поддерживается штатный образ Vast.ai с `/workspace/ComfyUI`, `/venv/main` и Supervisor в `/etc/supervisor/conf.d`.

## При пересоздании пода

API-workflow не содержит адреса сервера. На новом поде шлюз создаёт новый **файл подключения**: импортируйте его на сайте. Нужный API-workflow можно загрузить снова; сайт сам найдёт промпт, seed, размер и sampler. Установка недостающих моделей/нод через загрузку workflow не производится — сайт покажет, чего не хватает.

Чтобы шлюз ставился автоматически вместе с ComfyUI, в provisioning-скрипте после моделей запустите ту же команду установки из GitHub. Подготовленный персональный шаблон Vast.ai должен ссылаться на этот репозиторий, а файлы в ветке `main` должны быть опубликованы до запуска нового пода. Обновления `main` будут использоваться при следующих установках.

## Приватность

- На GitHub находятся только исходники и безопасный базовый workflow, без ваших промптов, фотографий и ключей.
- Запросы, workflow и картинки идут из браузера напрямую на ваш шлюз. GitHub Pages не обрабатывает генерации.
- Ключ нужен для всех API-запросов. Он хранится только в памяти вкладки, без localStorage/cookie/аналитики. После обновления страницы подключитесь снова.
- Установщик добавляет защиту в сам ComfyUI: история, картинки, задания, пользовательские файлы и WebSocket требуют авторизации. Для прямого интерфейса ComfyUI используйте логин **studio**, пароль — `key` из файла подключения. Служебные схемы нод и readiness доступны без ключа для штатного запуска образа.
- `/workspace/krea-connection.json` содержит ключ: не загружайте его в GitHub и не отправляйте другим людям. Он исключён из Git через `.gitignore`.
- Галерея сайта хранится в памяти вкладки. PNG остаются в `temp/output` ComfyUI и исчезнут при уничтожении пода. Скачивайте нужные изображения.
- Защита шлюза не заменяет авторизацию SSH/Jupyter/Instance Portal/Syncthing. Если открыть эти службы публично без авторизации, через них можно получить файлы пода. Сохраняйте штатную авторизацию Vast.ai и не делитесь ссылками/паролями доступа.

## Ограничения импорта

Автоматически поддерживаются строковые промпты `PrimitiveString*`, `CLIPTextEncode`, seed `KSampler`/`RandomNoise`/`Seed (rgthree)`, размер `Empty*Latent*`, шаги/CFG первого KSampler. Выбор основного текстового поля доступен вручную. Seed заменяется новым положительным числом при каждом API-запросе; frontend-режим `-1` не пересылается на сервер.

Произвольные API-workflow с другими схемами полей могут требовать адаптации. Для нескольких latent/sampler меняется основной найденный узел, остальные сохраняются. Сайт получает изображения из всех `images`-выходов ComfyUI; для результата нужен `PreviewImage` или `SaveImage`/совместимый узел. Видео не поддерживается.

Базовый workflow — проверенная FP8-генерация без GGUF и детализации, с очищенным примером промпта. Ваш оригинальный API-файл не редактируется. Значение 1500 для latent даёт 1496×1496; итоговый фактический размер показывается у картинки.

## Локально на ПК

В этой папке запустите `python -m http.server 8766 --bind 127.0.0.1` и откройте `http://127.0.0.1:8766`. Это тот же сайт. Открытие `index.html` двойным щелчком ограничивает автозагрузку workflow из-за правил `file://`; используйте локальный HTTP-сервер или GitHub Pages.

## Службы на поде

```bash
supervisorctl status krea-studio krea-studio-tunnel comfyui
tail -n 50 /workspace/.krea-studio/gateway-error.log
tail -n 50 /workspace/.krea-studio/tunnel.log
```

Шлюз слушает только `127.0.0.1:18189`, HTTPS предоставляет Cloudflare Tunnel. Постоянный домен не требуется. После пересоздания туннеля скачайте актуальный файл подключения. Ключи на поде: `/workspace/.krea-studio/`, права 700/600.

## Проверка

Базовая API-генерация проверена на RTX 3090: запрос `/prompt`, получение `/history` и PNG через `/view`, около 36 секунд. Новый шлюз проверен локальными HTTP-тестами: авторизация, CORS без cookies, отсутствие доступа к служебным файлам, новые seed, получение картинки и отмена своего задания. Интерфейс проверяется отдельно на локальном тестовом API. Полная установка шлюза на новом GPU-поде требует финальной проверки: предыдущий под удалён пользователем.

## Очередь генерации (обновление)

Выберите от 1 до 20 изображений и нажмите «Добавить в очередь». Каждое изображение отправляется отдельным заданием (`count: 1`) с собственным seed. Пока GPU занят, можно менять промпт и отправлять новые задания. Очередь и статусы живут в памяти открытой вкладки; не закрывайте её до получения результатов. ComfyUI выполняет задания последовательно, не одновременно. Для работы нужен установленный API-шлюз с маршрутами `/api/generate`, `/api/job/{id}`, `/api/image` и `/api/cancel`.

## Пакеты промптов и готовые кадры

Инструкция доступна на самом сайте по кнопке **Как пользоваться**. Включите «Список промптов»: одна или любое число пустых строк разделяют описания. Простые переносы внутри описания сохраняются. До 100 промптов за пакет; до 200 незавершённых заданий. Можно загружать .txt или вставлять текст. «Изображений на каждый промпт» умножает число заданий: 20 промптов × 2 = 40. Отправка не ждёт завершения генерации; шлюз ставит задания в очередь ComfyUI. На одном GPU выполнение обычно последовательное.

Кнопка отправки находится сразу под промптом. Раздел «Очередь» показывает статусы и позволяет отменять отдельные задания. «Готовые кадры» — выбор фотографий, «Выбрать все», скачивание выбранных или всех фотографий одним ZIP. ZIP создаётся в памяти браузера, без сторонних библиотек и отправки фотографий третьим сторонам. Перед закрытием вкладки скачайте результаты.

Проверки обновления: разбиение 20 промптов с разным числом пустых строк, многострочный промпт, одиночный режим, CRC32 и ZIP стандартным Python zipfile; HTTP-тесты авторизации, CORS, новых seed и адресной отмены по ID. В браузере используется локальный имитатор API; новые функции очереди не проверены на новом GPU-поде.
